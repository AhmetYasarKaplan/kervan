# Security policy

Report a suspected vulnerability privately using **Report a vulnerability** on
the repository's GitHub Security tab. Include affected versions, a reproducer,
and the expected impact when possible. Do not put exploit details in a public
issue. If private reporting is unavailable, open an issue requesting a private
contact channel without disclosing the vulnerability.

Dependency updates are proposed weekly. The repository submits its Gradle
dependency graph to GitHub so enabled vulnerability alerts can cover resolved
dependencies. Maintainers review alerts and publish fixes through the normal
release process.
